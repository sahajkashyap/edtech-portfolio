# What changed on 5 August 2026, and why

19 commits. 54 files changed, 3791 insertions(+), 483 deletions(-). This is the record of what moved and why.

The reason for each change is the point of this file. A list of what changed is
a changelog; a list of WHY is the thing that stops the same mistake next time. The short version of the day: the project was not
over-reviewed, it was **under-instrumented**, and a large share of what later
reviews found was damage done by earlier fixes.

---

## 1. Three checkers were asserting things that had stopped being true

**`check_register` said "no field anywhere in these files tells the examiner
otherwise."** False. Every passage carried a `scoring_note` saying a child who
reads "don't" for "do not" must not be marked wrong. `sync_index.py` only carried
a different field to the screen, so on all 27 passages **the teacher panel was
empty**. The warning had been written, saved, and shown to nobody.

Fixed by carrying it through, building it per lesson from the forms that lesson
actually contains, and changing the check from *assume it is missing* to *verify
it names every form*. The stronger check immediately found three word lists with
the same defect and no note at all.

**`check_notes` quoted a line of renderer code that no longer existed.** Notes had
moved to the examiner's panel in an earlier commit. Severities kept — the panel is
still an arm's length from the child — but the stated reasons are now true.

**`CONTEXT_ASSUMPTIONS["a pet"]` matched the verb.** *"She pets it"* fired a check
about whether the household owns an animal.

## 2. Two sign-offs were silencing nothing

Both entries in `ACCEPTED` matched no finding. One was keyed on the rule's
*reason* where the code keys on its *name*, so it **could never have matched on
any run since the day it was written**. A sign-off is a promise that a person
looked; a dead one spends that promise on nothing.

`dead_signoffs()` now fails the run, with a test proving it fires.

## 3. Five character names were making miscues unscoreable

`pam`, `meg`, `deb`, `ned` and `raj` each reverse into a word the child already
knows: `map`, `gem`, `bed`, `den`, `jar`. Reversal is *the* five-year-old error,
and a name that reverses into a real word means the examiner cannot tell a
reversal from a meaning error. Those mean opposite things about a reader.

Replaced with `Min`, `Lin`, `Kip`, `Jin` by a finder that checks decodability,
reversal, edit distance and common-noun collision at once. At Lessons 15 to 21,
exactly one name in a 56-name pool clears all four.

## 4. Eight passage rewrites were reverted, because they made things worse

Mid-morning I rewrote twelve passages to clear checker findings. An independent
review judged them lesson by lesson: **eight to revert, seven to partially fix.**
The rewrites had cleared findings on measured axes by introducing errors on
unmeasured ones:

- *"Buds rot in a hot bin"* (true) became *"Mud can rot in a hot bin"*. **Mud does
  not rot.** A true sentence was made false to dodge a regex.
- *"sets a bun"* (correct) became *"tips a bun"*. You tip a container.
- Four rewrites deleted the physical step that made the ending true, leaving the
  resolution asserted rather than performed.
- Lesson 22: *"Do not tap it,"* then a verb swap made the next line **hit the bug
  with a pot.**

The finding count went *up* when these were reverted. That rise was the correction.

## 5. The writing standard was a specification nobody had built

`WRITING-RULES.md` holds **53 rules, 18 marked [MECHANICAL]**, each shipping the
check that would enforce it and naming the file it belonged in. It had been
written the day before as a diagnosis of this exact corpus, naming lessons by
number. Nothing executed it. Twelve passages were rewritten straight through it.

`formb/audit_writing.py` now executes the mechanical ones. Each check has a
self-test proving it fires on its own example **and** stays quiet on a clean
passage. Writing-rule HIGH findings went **102 → 14**, and the backlog is
recorded in the manifest so it can only shrink.

Along the way it audited word lists for the first time — a quarter of the
instrument that had never met the writing rules at all.

## 6. Eleven bugs in the tool, two of them corrupting data

Nothing had ever *opened the page* until an independent QA pass drove it.

**Every word-list lesson scored wrong.** The nine word lists put each *sentence*
on the page as one clickable item, so a child who read *"Sam and I tap the mat."*
was recorded as having read **one word**, and one misread word cost the whole
sentence. Words read, accuracy, error ratio and rate were wrong on nine of 36
items.

**Stale records opened silently.** The fit check compared word *counts*. Of 21
lessons edited that day, 14 kept the same count — so a record saved against old
text opened with no warning and painted the saved words over the new page, and
printed that way.

Also: `Cmd+P` toggled Pause instead of printing, on a tool whose entire output is
a printed record. A pending save was discarded by every path that left a record.
A failed storage write was completely silent. Reopening a record mid-read gave a
frozen clock that claimed to be running. Undo could not undo *Clear every mark*.

## 7. Word lists stopped being banded on the passage scale

The one finding that produced a **wrong decision about a child**. A word list is
17–22 scored items against a Form A passage of 31–61 words. Same child, same three
errors: **95.1% Independent** on one, **86.4% Frustration** on the other. All nine
flipped; at two lessons, two errors were enough. And 41–48% of the scored items
are sight words, so it was never a decoding percentage: Lesson 8 scores the word
"I" four times, 21% of the sheet.

Word lists now report the count and say the band does not apply.

## 8. Six defects in the checkers built that same day

An adversarial audit of my own new code:

- **Rule 4.1 was blind to adjectives.** *"the bin"* flagged, *"the red bin"*
  invisible. The highest-volume rule in the file.
- **The `agreement` rule had the same blindness** — and it exists *because* an
  automated fix had inserted eight bad articles in one pass.
- **The manifest was not hashing the two newest checkers.** Demonstrated
  consequence: gut `audit_writing`, findings drop, the self-test still passes,
  the manifest is byte-identical, and the suite reports the drop as **good news**.
  A weakened checker read as an improvement.
- The accepted-baseline reason was erased by the next ordinary re-stamp, though
  the commit that added it promised it persisted.

## 9. MSV cue analysis and a retell capture

The gap I had been scoring wrong. I was grading the tool against *is this a
complete Clay running record* and marking it down for not **interpreting** the
child — which is not what it is for. See `DESIGN.md`.

The teacher taps M, S or V on each miscue; the tool tallies and reports *"4 of 4
miscues coded — these are counts of what you marked, not a judgement."* Plus a
retell box and four buttons. Capture and arithmetic, no inference.

## 10. A worked example, and a way out of the tool

The repo had **no evidence of use**: everything in it was a closed loop where the
system verified itself against rules the same person wrote.

`worked-example.html` is one finished record — a child called Maya reading
Lesson 20. She is invented, and the page says so in bold before anything else.
The numbers are not: every one was produced by marking the real passage through
the real interface, click by click, then reading the values back out.

It also makes the argument for the tool better than prose could. Maya drops the
`-s` three times, on the lesson named for the `-s`, and gets every base word
right. Her accuracy says *Instructional*, which tells a teacher to carry on at
about this level. It does not tell them what to teach. The pattern does.

Separately: the tool had **one link in 1,879 lines**, and it was the CSV export.
A visitor could not reach the lessons, the example, or the source from the page
they were being asked to judge.

## 11. What the tool decides, written down

`DESIGN.md`. The principle the day arrived at, in one line: **the teacher decides,
the tool counts.** It states where the line sits for cue analysis specifically, and
what that rules out: no suggested reading level, no recommended next lesson, no
risk flag, no inference from marks to cause. *If any of those ever appear, the
tool has stopped being a record and started being an opinion.*

**Why it needed writing down.** For most of the day I was grading this tool
against *is it a complete Clay running record*, and marking it down for not
interpreting the child. That put software in exactly the place it should not be.
Once the question became *does the teacher have every piece, correct and fast*,
the gap closed in an afternoon. A principle you only hold in conversation is one
you will drift from at the next decision.

## 12. Two lessons started telling the examiner they cannot measure their own sound

Lessons 22 and 34 are named for `k` and `z`, and at both, every word carrying that
sound is already spent by the practice form the child has read. That was recorded
honestly, with the arithmetic, in `audit_writing.ACCEPTED`.

**Which is in the test suite, where an examiner never looks.** The teacher marking
Lesson 22 is the exact person who needs to know the score is not a check on `k`,
and the tool was not telling them. Both now carry a `limit_note` that renders
**first** in the teacher's panel, above the contraction warning and everything
else, because it changes how the entire score is read.

Found by the proofread of the README, not by any of the eleven review agents:
the README claimed those two items "state on their own sheet" what they cannot
measure. They did not. Rather than soften the sentence, I made it true.

## 13. The README, rewritten for someone who has never taught

The repo was public and GitHub Pages was live all day, and **the README did not
mention this tool once.** GitHub renders that same file on the repo page *and* at
the homepage URL, so anyone arriving from a LinkedIn profile landed on a page
where the day's work did not exist.

It now opens with what a running record is, in plain English, before any software
is mentioned. An independent proofread against the recruiter test then found five
things that had to change, three of them factual:

- **"36 passages" was wrong.** It is 36 items: **27 passages and 9 word lists.**
  The worst error the page could carry, because the opening argues that *what* a
  child got wrong matters more than *how many*, and a word list has no story to
  follow, so it cannot show you that. The distinction is now its own section.
- **The honesty paragraph was not honest** (see section 12).
- **The call-to-action block would have rendered as one run-on line** on GitHub,
  in the only place the page asks a reader to do anything.
- **"17 typos in the source curriculum" named a published program as having done
  badly**, and left it ambiguous whether the errors were theirs or mine in
  transcription. Now: *17 places where my curriculum data and the published
  sequence disagreed.*
- **The horse/pony example argues the meaning-cue case**, and much of the
  early-literacy field treats three-cueing as discredited, including the
  structured-literacy position the rest of the repo is built on. The README was
  making both arguments without noticing. It now says the disagreement exists and
  that the tool takes no side.

people aimed at it.

That last one is the sharpest: **I committed defect class A12 — "duplicated data

Knowing the class is not the same as having the check.

## The order that would have avoided most of this

Recorded as section H of `DEFECT-CLASS-CATALOGUE.md`:

```
1  FREEZE the artifact. No edits until step 4.
2  RUN every lens in parallel — the six roles in section G.
3  TRIAGE into ONE list. Verify each finding before acting.
4  FIX once, re-running the mechanical checks after each edit.
5  VERIFY once, all lenses, on the frozen result.
6  SHIP, or record what is left with its measurement.
```

Six passes each applied a *different* lens and each found its own class exactly
once, because each was the first time that lens had run. The dimensions were
already named in the catalogue that morning.
